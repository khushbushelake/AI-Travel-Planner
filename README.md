# ✈️ AI Travel Planner

An AI-powered travel planning application that generates personalized travel itineraries based on destination, duration, travelers, budget, travel style, and interests.

## 🚀 Features

- 🤖 AI-generated personalized travel itineraries
- 💬 AI travel chatbot with conversation memory
- 💰 Budget breakdown and trip cost estimation
- 🌦️ Real-time weather information
- 🗺️ Destination location map
- 📄 Download itinerary as PDF
- 📊 Trip summary with budget calculations
- 🎯 Personalized recommendations based on travel preferences

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- OpenWeather API
- OpenStreetMap / Nominatim
- ReportLab
- Pandas
- Requests
- python-dotenv

## 📋 How It Works

1. Enter your destination.
2. Select the number of days and travelers.
3. Enter your total budget.
4. Select your travel style.
5. Choose your interests.
6. Generate your personalized itinerary.
7. Ask follow-up questions using the AI travel chatbot.
8. Check weather and destination location.
9. Download the itinerary as a PDF.
